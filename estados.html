Estados y componentes

Cada petición a la API muestra uno de estos estados: cargando, error con reintentar o vacío (RNF-03).

Cómo se usan en las vistas

Cada zona que carga datos tiene data-region y adentro cuatro bloques: data-state="loading", "error", "empty" y "content". El JS deja visible solo uno (quitando o poniendo hidden). El botón Reintentar tiene data-action="retry". Detalles en GUIA.md.
